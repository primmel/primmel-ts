# 05 — One formula carrier

**Status: RESOLVED (2026-10-27), rescoped.** `calculation` is the formula
(notation + inputs/outputs; symbols and verdicts reference it — verified
across the corpus waves). `formulas_used` retired outright with the
three retract-candidates (primmel-ts#207 — the registry-index idea
died with the construct). **`formula_note` stays, by justification**: it
is not a second formula carrier — it is the shared-formula editorial
note (applies_to-bound; R 60's own caution structure, 2 uses in
oiml-r60-lml), whose text would otherwise duplicate across every
referenced calculation. One carrier for the math; one reference form
for the notes N formulas share.

## The gap
`calculation`, `symbol.formula`, `verdict.derive`, `formulas_used`,
`formula_note` — five carriers of "expression + inputs + result".

## The resolution
`calculation` is the formula (notation + formula + inputs/outputs — the
math plane). Symbols and verdicts REFERENCE calculations. `formulas_used`
becomes the registry index of the calculations a document uses.
`formula_note` retires. One carrier, four reference forms.
