# 12 — The layout facets move to a presentation sidecar

## The gap
`canvas`, `pages`, `view_profile` — MMEL-parity presentation geometry in a
language whose quarantine bans even a citation outside `description`. The
layout is derivation output, not model content.

## The resolution
The layout facets move to a presentation sidecar (the v2 bridge's domain —
the canvas file beside the model), or carry the explicit deprecation
disposition in registry-triage. The model language stops carrying geometry.
